## 4. 종합 — 반복되는 핵심 연출 문법

### 4-1. 구조: 3레이어 교차 편집
- **P(퍼포먼스) / M(기억) / N(현재)** 세 레이어를 교차시킴. P는 **접착제** 역할 — 시간대가 바뀔 때마다 P를 끼워 넣어 점프를 자연스럽게 함 (예: S20 → S21, S22 → S23, S38 → S39)
- **흐름**: 오프닝(M, 손) → 현재 일상(N, 밝고 담담) → 가수 등장 + 이별 가사(P)로 앞 장면 재해석 → 후렴부터 M이 늘어나고 → 후반에 M이 주도 → 최종 P 클라이맥스 → M 뒷모습 → 손으로 수미상관
- **"슬픔을 슬프게 찍지 않는다"**: 이별 서사지만 N은 밝은 일상, M은 행복한 웃음으로만 채움. 슬픔은 **가사와 대비**에서 생김

### 4-2. 촬영·구도
- **손 CU 모티프 3회**(S01 → S47 → S50): 얼굴 없이 관계를 말함. 같은 구도에 동작을 하나씩 더해 반복의 의미를 키움
- **숏-리버스숏 CU 쌍**(S34/S35, S44/S45): 오프스크린 시선을 서로 맞춰 대사 없는 대화를 만듦
- **디테일 인서트**(음료 S05, 토스터 S07, 에스프레소 S29): 광고식 CU로 일상에 질감과 리듬
- **혼자 vs 함께 대비 쌍**: 혼자 걷는 발(S10) ↔ 함께 건너는 횡단보도(S36) / 혼자 자전거(S18) ↔ 둘이 자전거(S32) / 행복한 턱 괴기(S02) ↔ 지친 턱 괴기(S30) / 혼자 토스트 먹는 주방 ↔ 파티 주방(S42)
- **평행 편집**: A와 B의 일상을 번갈아 보여 줌(S03 ↔ S06, S11 ↔ S13, S15 ↔ S16, S25 ↔ S26) — 둘 다 폰을 보는 등 행동을 대칭으로 맞춤
- **전경 레이어**(S12 나뭇잎)와 **프레임 속 프레임**(S13 아치)으로 깊이 추가
- **Shot Size 분포**: WS는 장소 설정용으로 아껴 쓰고, 감정은 MS~CU에 집중

### 4-3. 카메라 움직임
- 분석 결과상 대부분 **고정 또는 미세한 움직임**. 명시된 움직임은 S20 풀백, S48 앵글 변화뿐
- 원칙: **카메라는 조용하게, 움직임은 인물이**. 카메라가 크게 움직이는 곳은 클라이맥스(S48)에만 아껴 둠
- 퍼포먼스는 곡 강도에 따라 CU → MS → 풀백 → 측면 → 일어섬 순으로 **점진적으로 확장**

### 4-4. 조명·색감 (레이어별 컬러 스크립트)
| 레이어 | 조명 | 색 | 의상 |
|---|---|---|---|
| M 기억 | 골든아워 역광, 소프트 | 따뜻한 앰버, 필름 룩 | **흰색** (흰 셔츠·흰 블라우스) |
| N 현재 | 밝고 균일한 주광/실내광 | 중성·파스텔, 포인트 원색(민트 냉장고, 빨간 토스터, 빨간 파라솔, 오렌지 후디) | 컬러풀, 캐주얼 |
| P 퍼포먼스 | 로우키 단일 스폿(톱 → 하드 → 역광 → 엣지로 변주) | 흑 + 백 | 흰 셔츠 |

- **흰 옷이 세 레이어를 묶음**: 가수의 흰 셔츠 = 기억 속 두 사람의 흰 옷. 관객은 의식하지 못해도 가수가 "기억을 노래한다"고 느끼게 됨
- 조명 변화로 감정 강도를 조절: 가사가 격해질수록 스폿이 정면 → 역광으로 이동(S31)

### 4-5. 편집·리듬
- **Shot 길이 = 감정 온도**: N(일상) 2~4초로 빠르게, M(기억) 3~9초로 머물고, P(퍼포먼스)는 클라이맥스에서 13초·20초로 길게 끌고 감
- **1초 플래시 컷**(S14)로 가수를 상기시킴
- **회상 전환 문법**: 인물이 폰을 보다 고개를 듦(S39 → S40) → 바로 기억(S41)
- **고조 → 이완 교차**: 크레셴도(S20) 바로 뒤 부드러운 기억(S21), 가장 밝은 파티(S42) 바로 뒤 그리움 퍼포먼스(S43)
- **북엔드**: 같은 장소·같은 손 구도로 열고 닫음 + 엔딩 무음 카드

### 4-6. 음향
- 전 구간 곡이 주도하지만 **디제틱 효과음이 음악 위로 튀어나옴**: 토스터 "띵"(S07), 에스프레소(S29), 폭죽(S42), 풍선(S46). 발라드에 리듬 포인트와 현실감을 줌
- **가사-화면 직결은 딱 두 번**: 이별을 말하는 가사(S09)가 가수 첫 등장에, 후렴(S17)이 Shot Size 확장에. 나머지는 화면이 가사를 직접 설명하지 않음
- 인트로는 악기(바이올린)만 → 보컬 시작과 인물 첫 등장을 맞춤(S02) → 끝은 페이드아웃 → 무음 엔드카드

## 5. 새 영상에 적용하는 제작 체크리스트

1. **레이어 3개를 먼저 설계**: 화자(퍼포먼스 또는 내레이터) / 과거(따뜻함) / 현재(담담함). 각 레이어의 조명·색·의상 규칙을 한 줄씩 정해 둠
2. **반복 모티프 1개**(손, 물건, 장소)를 정하고 오프닝·중간·엔딩에 3번 배치. 반복할 때마다 동작을 하나씩 더함
3. **대비 쌍 3~4개**를 기획: 같은 장소/동작/포즈를 "혼자 vs 함께"로 두 번 찍음
4. **에셋 재사용 설계** (AI 제작 효율의 핵심):
   - 캐릭터 레퍼런스 3종(A, B, 화자) — 모든 Shot의 일관성 기준
   - 배경 마스터 플레이트: 주방 / 공원 / 강변 / 스튜디오 / 카페 (5장으로 전체 Shot의 약 70% 커버)
   - 손 CU First Frame 1장 → 오프닝·엔딩 공용
5. **퍼포먼스는 길게 뽑아서 잘라 씀**: 립싱크가 가장 어렵고 비싸므로, 긴 클립 몇 개를 만들어 1~5초 인서트로 나눠 사용. 측면·역광·실루엣 앵글로 립싱크 부담 줄이기
6. **카메라는 대부분 고정**으로 생성(AI 결과가 가장 안정적) → 편집 리듬으로 에너지를 만듦. 큰 카메라 움직임은 클라이맥스 한 곳에만
7. **효과음 포인트 3~4개**를 음악 위에 배치(생활 소리)
8. **Shot 길이 규칙**: 일상 2~4초 / 감정 4~8초 / 클라이맥스 10초 이상(분할 생성 후 연결)
9. **엔딩**: 가장 넓은 화면(뒷모습) → 오프닝 반복 CU → 무음 텍스트 카드
